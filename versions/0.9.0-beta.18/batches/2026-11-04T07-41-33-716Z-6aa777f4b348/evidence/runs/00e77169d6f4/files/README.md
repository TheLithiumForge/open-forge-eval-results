# Neon Pairs
Find every matching pair in a silent, offline memory game. Implements the [version 2.2 product specification](docs/README.md), including all seven grid sizes, deterministic board codes, version 1 snapshots and the replay CLI.

Open **[dist/index.html](dist/index.html)** directly in a browser. This is the complete distribution: scripts, styles and SVG artwork are inline. It needs no server or network connection. For persistent size preferences and best scores, use a local HTTP origin; file-URL storage behavior depends on the browser. Storage failures leave the session playable.

## Development

Use Node.js 24.19 or later and npm. Dependencies are pinned in `package.json` and `package-lock.json`.

| Command | Result |
| --- | --- |
| `npm ci` | Install the locked dependencies |
| `npm run dev` | Start the local development server |
| `npm run typecheck` | Check browser and Node compiler projects |
| `npm test` | Run the pure game and storage unit tests |
| `npm run test:e2e` | Build current source, then test that build in fresh browser contexts |
| `npm run build` | Type check and write the standalone `dist/index.html` |
| `npm run --silent replay -- PATH` | Validate a replay and print only its final snapshot JSON |

Install Chromium for browser tests if it is not already present: `npx playwright install chromium`.
The browser test command stops if the build fails and starts its own temporary preview server.

## Play and reproduce

Select Grid size, then reveal cards with click, tap, Enter or Space. Use arrow keys to move through the board and Tab to leave it. Matches stay open; mismatches close after 800 active milliseconds. Hidden-page time is excluded. Restart repeats the deal; New Game changes its seed.

Open **Reproduce a game** to load a board code such as `np1-4-1`. Export snapshot fills the text area with readable JSON for manual copying. Load snapshot restores unfinished progress paused; Resume continues its clock and remaining mismatch interval. Completed imports stay static and do not record a best score. Only the chosen size and best move counts persist automatically.

For example, save this as `example-replay.json`:

```json
{"version":1,"boardCode":"np1-4-1","actions":[{"atMs":0,"index":0},{"atMs":0,"index":11}],"endMs":800}
```

Run `npm run --silent replay -- example-replay.json`. The final snapshot has matched positions `[0,11]`, one move and 800 elapsed milliseconds. Invalid or unreadable files produce no stdout, an error on stderr and a nonzero exit code. Replay is available only in the CLI and game core.

## Code arrangement

The implementation follows [Architecture](docs/architecture.md):

```text
src/
  main.tsx                 DOM entry point
  Game.tsx / Game.css       Composition and page layout
  game/
    boardCode.ts           Exact parser, Park–Miller and unbiased shuffle
    state.ts               Immutable transitions and logical time
    snapshot*.ts           Version 1 encoding and complete validation
    replay.ts              Pure timed-action replay
    board/                 Cards, SVG faces, roving focus and board styles
    controls/              Native deal and reproduction controls
    session/               React state, monotonic clock, visibility, storage
scripts/replay.ts          Node file and process adapter
tests/                    Complete browser and CLI journeys
```

Focused unit tests live beside their behavior. The pure core reads no browser clock, DOM, storage or external randomness. The browser session supplies those effects. Hidden cards mount no face SVG or identity attributes. No test fixtures, solver API, audio, analytics, external fonts or assets ship in the distribution. Authored TypeScript files stay below 200 lines.

## Validation evidence

Tested on 4 November 2026 with **Node 26.12.1**, **npm 11.20.0**, **Playwright 1.64.1** and **Chromium 156.0.8078.4**, using the exact package pins in [Technology](docs/technology.md).

The locked install (`npm ci`), separate compiler checks, production build, **87 unit tests** and **27 browser journeys** passed. Unit checks include independent literal deal vectors, rejection sampling, all supported sizes, move and time caps, exact mismatch boundaries, strict snapshot and replay validation, UTF-8 limits and storage failures.

Browser evidence is generated by `npm run test:e2e`. The journeys cover completion at every size; pointer, touch and keyboard input; focus and Tab behavior; repeated live announcements; saved scores; paused imports; stale timer invalidation; simulated document-visibility events; the replay process contract; and a complete game opened from `file:` with HTTP requests blocked. Layout checks cover 360x800, 1280x800 and 640x400 at device scale 2, including all 256 cards, internal scrolling and complete focus outlines. Reduced-motion and static imported-win behavior are checked too.
