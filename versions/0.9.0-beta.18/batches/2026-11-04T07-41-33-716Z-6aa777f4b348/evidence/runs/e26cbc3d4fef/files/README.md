# Neon Pairs

A silent, offline memory game built from the [version 2.2 specification](docs/README.md).
Open [dist/index.html](dist/index.html) directly to play. Choose a size, reveal two
cards and find every pair. New Game deals again; Restart repeats the current deal.

Expand **Reproduce a game** to load a board code or export and load a snapshot.
Unfinished snapshots wait for Resume. Progress stays in memory until exported;
only the chosen size and per-size best move counts are saved automatically.

Use Node.js 24.19 or later and npm. Dependencies are exactly pinned in
`package.json` and `package-lock.json`.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

`npm run test:e2e` first type checks and builds current source, and stops if that
build fails. Playwright serves that build over local HTTP and gives every journey
a fresh browser context. `npm run build` produces one `dist/index.html` with all
scripts, styles and SVG artwork inline. Playing requires no network access.
Use a local HTTP origin to check saved preferences because browser storage differs
on file URLs; unavailable storage leaves the current session playable.

Run a version 1 replay with:

```sh
npm run --silent replay -- PATH
```

Valid input prints only the final snapshot JSON to stdout and exits 0. Invalid or
unreadable input keeps stdout empty, writes a message to stderr and exits nonzero.
The [reproduction specification](docs/reproducibility.md) defines all three formats.
There are no replay controls or diagnostic interfaces in the game UI.

Pure generation, rules, time, snapshots and replay live in `src/game`. Browser
session effects and storage belong in `src/game/session`, board navigation and
cards in `src/game/board`, and controls in `src/game/controls`. `src/Game.tsx`
composes them. Components keep their props and styles beside them. Focused tests
sit beside their behavior; complete browser journeys live in `tests`. The app,
Node tools and tests each have a separate strict TypeScript project. At delivery,
all 56 authored TypeScript files are at or below 128 lines.

The named compatibility combination was tested on 4 November 2026: Node
**26.12.1**, npm **11.20.0**, Playwright **1.64.1** and Chromium
**156.0.8078.4** (headless). TypeScript **7.0.2** and Vitest **5.0.5** were used.
Other supported runtime versions have not been separately verified.

Browser journeys cover complete games at every size, turn timing and caps, saved
preferences and best scores, storage failures, snapshot imports/exports, paused
Resume focus, stale timers, native input, repeated announcements and hidden-card
DOM privacy. The 16x16 layouts were measured at 360x800 and 1280x800; both 4x4 and
16x16 were checked at 640x400 with device scale 2. First, last and mid-board focus
outlines stay fully visible. Native touch gestures reach both scroll axes before
tapping the first and last cards. The built HTML was also played directly from
disk with networking blocked and zero HTTP requests.

The visibility journey supplies a test-only `document.hidden` value and native
`visibilitychange` event because headless Chromium keeps background tabs visible.
It verifies that the same remaining active time drives both clock and mismatch;
the shipped session listens to the browser's normal visibility signal.
