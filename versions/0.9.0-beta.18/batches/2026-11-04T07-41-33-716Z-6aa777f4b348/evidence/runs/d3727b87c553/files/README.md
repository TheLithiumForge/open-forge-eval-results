# Neon Pairs

Open [dist/index.html](dist/index.html) directly to play offline. The single file includes React, styles and SVG artwork; play needs no network, service or account. Preferences persist where browser storage is available. Use a local HTTP origin when checking saved size and best scores.

Use Node.js 24.19 or later and npm. Exact dependency versions are pinned in `package.json` and `package-lock.json`; requirements start in [docs/README.md](docs/README.md).

| Command | Result |
| --- | --- |
| `npm ci` | Install locked dependencies |
| `npm run dev` | Serve development locally |
| `npm run typecheck` | Check browser, Node and test compiler projects |
| `npm test` | Run colocated unit tests |
| `npm run test:e2e` | Build current source, then run browser journeys against that build |
| `npm run build` | Type check and emit the offline HTML |
| `npm run --silent replay -- PATH` | Print the final snapshot for replay JSON |

Replay prints only snapshot JSON to stdout and exits 0 on success. Invalid files print only an error to stderr and exit nonzero. For example, save the [documented replay](docs/reproducibility.md#replay) as `replay.json`, then run `npm run --silent replay -- replay.json`.

The architecture follows [docs/architecture.md](docs/architecture.md): pure generation, transitions, logical time, snapshots and replay live in `src/game`; browser clocks and preferences in `src/game/session`; navigation and inline SVG cards in `src/game/board`; native controls in `src/game/controls`. `Game.tsx` composes these behaviors. Focused tests sit beside their behavior; complete browser journeys live in `tests`. No development fixtures or solver interfaces ship in the game.

The named compatibility combination was tested on 4 November 2026: Node **26.12.1**, npm **11.20.0**, Playwright **1.64.1**, and Chromium **156.0.8078.4**. `npm ci` passed with the locked dependencies; `npm run typecheck` passed all three compiler projects; `npm test` passed **93 tests in 7 files**; `npm run build` emitted the single offline HTML; and the final `npm run test:e2e` fresh build passed **38 browser journeys**. Other runtime combinations have no recorded results.

Browser checks use fresh contexts and the built HTML, including `file:` loading with network access blocked, HTTP storage, every supported board size, exact logical timing, keyboard and touch input, imports, announcements, large boards and equivalent 200% zoom. Controlled browser clocks and visibility events verify active timing. The browser command stops on a failed build. Playwright owns and stops its local HTTP server.

The 44px grayscale sheet was visually reviewed: all 128 identities remain distinguishable by shape, marker and fill, including solid and outlined squares with diagonal markers. The phone, desktop and equivalent zoom layouts and their full focus outlines were also checked.

No screen reader was used. Automated accessibility-tree evidence is provided; spoken output and a real device's long-press context menu remain user acceptance checks as specified in [Input](docs/input.md#screen-reader) and [the document map](docs/README.md#out-of-scope).
