# Neon Pairs
Find every matching pair on boards from 4x4 to 16x16. Play with a mouse, touch or keyboard. The game is silent.

Open **[dist/index.html](dist/index.html)** directly from disk. This single file includes React, styles and SVG artwork and needs no network access.

Use arrow keys to move between cards, Enter or Space to reveal, and Tab to leave the board. New Game deals another board; Restart repeats the deal. Under **Reproduce a game**, load a board code or export and copy a snapshot. Unfinished snapshots load paused; Resume returns focus to the remembered card. Progress stays in memory until exported. Size and best moves are saved when browser storage is available; use a local HTTP origin to check persistence.

## Commands

Use Node.js 24.19 or newer and npm. Dependencies are pinned in `package.json` and `package-lock.json`.

| Command | Result |
| --- | --- |
| `npm ci` | Install the locked packages |
| `npm run dev` | Start the development server |
| `npm run typecheck` | Check the separate browser and Node projects |
| `npm test` | Run focused unit tests beside their behaviors |
| `npm run test:e2e` | Type check, rebuild, and test that build in fresh Chromium contexts |
| `npm run build` | Type check and produce `dist/index.html` |
| `npm run --silent replay -- PATH` | Print a valid replay's final snapshot, or report an error on stderr and exit nonzero |

Install the pinned browser if needed with `npx playwright install chromium`. Browser checks start and stop their own local preview server and refuse to reuse an existing server.

Try `npm run --silent replay -- examples/pair.replay.json`. It prints one matched pair, one move and 800 elapsed milliseconds. Replay has no browser UI.

## Code structure

- `src/game/`: pure deterministic deals, state, turn transitions, logical time, snapshot validation and replay.
- `src/game/session/`: React session state, monotonic active clock, visibility, random seed selection, announcements and validated preferences.
- `src/game/board/`: native card buttons, roving focus, navigation and face SVGs.
- `src/game/controls/`: deal and reproduction controls with their styles.
- `src/game/Game.tsx`: composition of controls, status and board.
- `scripts/replay.ts`: Node file adapter around the pure replay function.
- `e2e/`: application journeys and development-only evidence generation. These are excluded from the distribution.

Strict TypeScript checks cover both compiler projects. Authored TypeScript files stay below 200 lines. There is no global store, router, solver endpoint or saved automatic game progress. The [specification map](docs/README.md) defines the complete requirements.

## Verification

Recorded on 4 November 2026 with **Node 26.12.1, npm 11.20.0, Playwright 1.64.1 and Chromium 156.0.8078.4**. The locked install, separate type checks, production build, all **91 unit tests** and all **25 browser journeys** passed on this combination. Other tool combinations have not been tested.

The browser suite checks all seven sizes, exact active-time mismatch boundaries, hidden-page pauses, replacement timers, imported pauses and Resume focus, counter caps, best-score persistence, malformed inputs, keyboard completion, repeated live announcements, context menus, pointer cancellation, touch, reduced motion and layout. It checks 360x800, 1280x800 and 640x400 at device scale 2. The offline journey opens the built HTML from disk with networking blocked and completes a game. Replay CLI checks cover stdout, stderr and exit codes.
